# yusufurus.com - Personal Portfolio Website

This is the official repository for my personal portfolio website, [yusufurus.com](https://yusufurus.com). I built this site to showcase my projects, technical skills, and journey as a developer in Belgium.

## 🚀 About the Project

This is a clean, modern, and fully responsive static website. The primary goal was to create a lightweight and fast-loading digital presence that represents my work and coding style.

## 🛠️ Tech Stack

*   **HTML5:** Semantic structure for better SEO and accessibility.
*   **CSS3:** Custom styling using modern techniques (Flexbox and CSS Grid).
*   **JavaScript (Vanilla):** Implemented for interactive elements and UI enhancements.

## ✨ Key Features

*   **Fully Responsive:** Optimized for all screen sizes from mobile phones to large monitors.
*   **Performance Focused:** No heavy frameworks or libraries—just clean, native code for maximum speed.
*   **Professional Layout:** Designed with a focus on user experience and readability.
*   **GitHub Integration:** Links to my latest repositories and projects.
